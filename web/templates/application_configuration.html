Password policy

Lengths count Unicode characters. Bcrypt has a hard cap of 72 UTF-8 bytes. Some characters use up to four bytes; choose a maximum comfortably below 72. Passwords over the byte cap are rejected, never truncated. Existing passwords remain valid.

    Tool settings

    The shared queue accepts up to 100 waiting scans. Lowering concurrency lets active scans finish before starting more work. Directory discovery uses at most 50 simultaneous requests per scan.

    Tool timeouts (minutes)

    Each tool is stopped if it exceeds its budget; the stage keeps whatever it produced by then. Range 1–1440 minutes. Changes apply to scans that start after saving.
